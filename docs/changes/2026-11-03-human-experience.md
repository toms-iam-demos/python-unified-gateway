# Human-centered shared presentation

The maintainer requested developer-brand consistency where appropriate and usable design throughout the site. The shared baseline now provides readable supporting text, comfortable controls, visible focus on both light and dark surfaces, keyboard disclosure behavior, section-link focus and sticky-navigation clearance, reduced motion and forced-color support.

Illustrated workups use larger text and a heading outline appropriate to full or embedded views. Missing optional workflow labels no longer leave empty status pills. Native evidence artwork and access controls are outside the presentation change.

The canonical frontend documents record WCAG 2.2 AA as the engineering target without claiming a conformance certification. Public source contains generic shared components and policy only. Private deployments retain their approved identity assets and record their own route, responsive, keyboard and deployment evidence. Recovery is to restore the previous presentation assets and containers.

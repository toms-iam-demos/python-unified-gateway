# Municipal demo: generic visual identity

The public package represents a fictional municipal procurement team. Its civic icon is original vector artwork; the hero uses CSS gradients. No official seal or location photograph is included. Navy, blue and restrained amber support task hierarchy; written labels supplement color.

The employee workspace layout is a demonstration, not an authenticated portal. No city credentials are requested. Synthetic reviewer personas do not provide identity or separation of duties.

Bundled Fjalla One and Open Sans fonts retain their license files in `app/static/brand/`. Sources: [Fjalla One](https://github.com/google/fonts/tree/main/ofl/fjallaone), [Open Sans](https://github.com/google/fonts/tree/main/ofl/opensans). Required font copyright and license attribution remains intact. Local assets avoid runtime image/font requests; optional Swagger assets are separate.
